# Map identity values to colors

Map identity values to colors

## Usage

``` r
identity_color(values, low = "#DCEEFF", high = "#08519C")
```

## Arguments

- values:

  Numeric vector of identity percentages (0-100)

- low:

  Color for low identity (default light blue)

- high:

  Color for high identity (default dark blue)

## Value

Character vector of hex colors
